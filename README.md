# Harish B — Developer Portfolio

A minimal, interactive terminal-themed developer portfolio built with **Vite + React 19**.

🌐 **Live Demo:** [https://harishhbaskar.github.io/portfolio](https://harishhbaskar.github.io/portfolio)

## Quick Start

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build and deploy to GitHub Pages
npm run deploy
```
